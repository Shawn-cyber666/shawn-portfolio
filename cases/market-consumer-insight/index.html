Market & Consumer Insight

ProblemMethodTool EvidenceLimitsLearning

01 / Problem

市场信号很多，判断仍然稀缺。

信息来自社媒 UGC、用户评论、媒体评测、竞品发布与行业动态。真正困难的是来源、偏差、分类和优先级。

02 / Method

保留证据，再形成结构。

  1. 01Market Signals
  2. 02Collection
  3. 03Evidence Check
  4. 04Classification
  5. 05Pain Point / Motivation
  6. 06Pattern
  7. 07Opportunity
  8. 08Strategy Input

03 / Tool Evidence

Signal Studio 用于验证方法，而不是制造答案。

工具支持搜索取证、真实语料输入、单品研判、竞品比较、图片证据与多格式导出。AI 参与归纳与草稿，人工负责事实核验、模式判断与策略选择。

04 / Limits

公开信号可以指向问题，不能自动代表市场。

  • 记录来源与时间范围
  • 说明样本与渠道偏差
  • 区分搜索结果与真实 UGC
  • 不虚构样本量和代表性
  • 不使用 vivo 内部复盘数据

05 / Learning
